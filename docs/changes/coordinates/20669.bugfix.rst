Fixed race conditions on free-threaded Python builds where creating the
first sky offset frame for a frame class from several threads at once could
raise ``RuntimeError: dictionary changed size during iteration`` or an
``AttributeError``, and where modifying the transform graph while another
thread was using it could leave its caches out of date. Out-of-date caches
could make the graph report an incomplete set of frames or frame
attributes, fail to look up a frame by name, or fail to find a transform
path.
