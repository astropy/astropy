``FLRW.age`` is now integrated in the scale-factor coordinate
``a = 1/(1+z)`` for every FLRW cosmology that reaches the numerical
integral, including radiation-free models with ``Om0 > 0``. The previous
``quad(z, inf)`` form could return a non-monotonic age. On Astropy 8.0.1
every built-in realization with ``Tcmb0 > 0`` first increases on a
unit-step grid in ``z ∈ [4787, 4809]`` (``Planck18`` at 4787,
``WMAP1`` at 4809; ``Δage ≈ +3.66e-7`` Gyr) and again near
``z ≈ 2.5e4``. Radiation-free cosmologies that actually call
``_integral_age`` (non-flat ``LambdaCDM``, ``wCDM``, …) first increase
near ``z ≈ 22600``. The FLRW identity ``lookback(z) = age(0) - age(z)``
then fails by that same residual (Planck18 ``R(4788) =
3.768436602769043e-7`` Gyr); lookback itself stays smooth. Those
jumps are quadrature failures, not a discontinuity in the Komatsu
et al. 2011 neutrino-density fit. The same non-injective age made
``z_at_value(Planck18.age, Planck18.age(4788))`` return
``z ≈ 4752.59`` instead of 4788.

At the domain edge ``z = -1`` the scale-factor form now raises
``ZeroDivisionError``, matching ``FLRW.lookback_time(-1)``.
