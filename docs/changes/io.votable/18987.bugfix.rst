Fix several problems with ``char`` and ``unicodeChar`` data. BINARY and BINARY2
``char`` values are now read and written as UTF-8 for every VOTable version, so
pre-1.6 files with non-ASCII text load with a W55 warning instead of failing.
Writing non-ASCII text to a pre-1.6 ``char`` column gives an E24 warning in every
format, or an error with ``verify="exception"``. Values longer than
``arraysize`` are truncated with a W46 warning, without splitting a character.
Characters outside the BMP in a fixed length ``unicodeChar`` field no longer
make the file unreadable, and strings in a column that has been widened are
no longer truncated when the table is written back to VOTable.
