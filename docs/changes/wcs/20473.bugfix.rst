Fixed a bug that caused ``Cutout2D`` and ``SkyCoord.contained_by`` to use
swapped pixel coordinates for WCS objects in which the latitude axis comes
before the longitude axis (e.g. ``CTYPE1='DEC--TAN'`` and
``CTYPE2='RA---TAN'``), resulting in cutouts centered on the wrong position and
incorrect containment checks. In addition, ``skycoord_to_pixel`` and
``pixel_to_skycoord`` now make use of the same machinery as
``WCS.world_to_pixel`` and ``WCS.pixel_to_world`` internally.
