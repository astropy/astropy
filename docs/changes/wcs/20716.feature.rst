Added a ``shared_cpdis`` argument to ``WCS`` that controls whether an alternate WCS without its own ``CPDISja``/``DPja`` keywords uses the unsuffixed lookup-table distortion of the primary WCS. By default this is done only for HST ACS and WFC3 files that follow the STScI convention of sharing these tables with all alternate WCSs, so that the alternate WCSs of existing HST files keep their distortion corrections.
