Models can now opt out of the check that the coordinate arrays and the data
have the same shape when fitting, by setting ``verify_dims_in_fitting`` to
``False``. This allows fitting models that return an array with a different
shape from their input, such as a model that convolves with an instrument
response and returns the result on a coarser grid. For compound models the
attribute must be set on one of the component models rather than on the
compound model itself.
